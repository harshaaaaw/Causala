CAUSALA — Decision Twin Architecture

One twin where every lever becomes point + 90% band + signed receipt. No cluster. One process.

Try in 60 seconds

  • • git clone + pip install -e ./causala -e ./ragforge
  • • causala quickstart ingests examples/warehouse.csv
  • • price +3% → demand 2.46% [1.985,2.935] audit cd98
  • • causala tui or open http://localhost:8000

Core guarantee

  • • Every answer has a source citation
  • • Every number has a 90% band, widened if thin
  • • Every run has a hash-chained receipt
  • • Every tenant sees only its graph

Swap later, API stays

  • • SQLite → Postgres, JSONL → S3, networkx → Neo4j
  • • contract simulate → point + CI + audit_id never changes
  • • Bayesian _fit_group seam in ingest.py
  • • Bearer JWT, per-tenant, idempotent ingest
